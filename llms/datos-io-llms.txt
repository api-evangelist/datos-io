# Datos IO

> Datos IO was a Silicon Valley data-management startup, backed by Lightspeed Venture
> Partners, that built RecoverX — an "application-centric" backup, recovery and
> data-mobility platform for cloud-native and distributed databases. Datos IO was
> acquired by Rubrik in 2018 and operated for a period as "Rubrik Datos IO" before the
> brand was retired. The company is no longer operating independently and publishes no
> live API, developer portal, or documentation.

## Product (historical)

RecoverX — backup, recovery and data mobility for cloud-native applications:

- Parallel data streaming for fast backup in native formats
- Semantic deduplication for storage efficiency (marketed as up to 90% reduction)
- Distributed metadata catalog enabling backup-anywhere / recover-anywhere
- Orchestrated, automated recovery across private, hybrid and public cloud

Supported data sources (as documented in 2018): Apache Cassandra, DataStax, MongoDB,
Couchbase, Amazon DynamoDB, and Microsoft SQL Server.

Ecosystem partners (as documented in 2018): NetApp, Cisco, Amazon Web Services,
Google Cloud Platform.
